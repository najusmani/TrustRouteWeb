Questions

What FLEXCUBE teams ask us.

What is TrustForge?

TrustForge is an AI agent for Oracle FLEXCUBE Universal Banking developers. You describe a change and upload your objects; it asks what it needs, agrees a plan with you, and delivers radxml, CUSTOM hook packages, release JavaScript and scripts ready to load in ODT.

Which FLEXCUBE releases does it support?

FLEXCUBE Universal Banking (FCUBS) 14.6 and 14.7. Output has been verified end to end on 14.7.0.6.0.

Does TrustForge change Oracle’s code?

No. Everything goes in the CUSTOM layer: the radxml CUSTOM section, the CUSTOM hook package and the CUSTOM release JavaScript. Oracle’s KERNEL code stays as shipped, which keeps upgrades safe.

What do I need to upload?

Development objects only: the function’s radxml, table definitions, and for processing changes the related packages or JavaScript. Never customer data, production data or passwords.

Which AI does TrustForge use?

TrustForge is built on Anthropic’s AI, with FLEXCUBE ODT knowledge, rules and checks built in. A private install can run on your bank’s own Anthropic, AWS Bedrock or Google Vertex account.

How much does it cost?

The Free plan includes radxml reviews and ODT questions, 5 a month. The Partner plan is $100 USD per seat per month with all job types and a usage allowance per seat. Banks can also arrange a private install.
