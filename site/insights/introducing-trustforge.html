Introducing TrustForge: an AI agent for Oracle FLEXCUBE customization

TrustForge is an AI agent, built on Anthropic, that turns a FLEXCUBE change described in plain words into files ready to load in ODT.

News9 November 20263 min readBy TrustRoute Technologies

Key takeaways

  • TrustForge turns a FLEXCUBE change described in plain words into ODT-ready files.
  • Every change goes in the CUSTOM layer; Oracle code stays as shipped.
  • Nothing is built until you approve the plan.
  • Supports FLEXCUBE Universal Banking 14.6 and 14.7; start free today.

Every bank running Oracle FLEXCUBE knows the pattern: a small change to a screen or a charge becomes weeks of analysis, scarce ODT specialists and a sizeable invoice. Today we are introducing TrustForge to change that.

What TrustForge is

TrustForge is an AI agent for Oracle FLEXCUBE customization, built on Anthropic’s AI. It works like a senior ODT developer on your team: it understands radxml, release layers and hook packages, and the rules that make a screen load, save and deploy. It supports FLEXCUBE Universal Banking 14.6 and 14.7, and its output has been verified end to end on 14.7.0.6.0.

How it works

  1. Describe: say what you need in plain words and upload your development objects: radxml, table definitions, packages or JavaScript.
  2. Discuss: TrustForge asks only what it needs and agrees the plan with you, item by item.
  3. Build: once you approve, it builds each file and checks it against ODT’s load and save rules.
  4. Deliver: you download the files, the deploy order and unit tests, ready to load in ODT.

Six kinds of job

New FLEXCUBE screens, changes to Oracle’s own functions in the CUSTOM layer, radxml reviews, hook packages and release JavaScript, Silent ODT for bulk generation and web services, and answers to ODT questions from the guides.

Built for how banks work

  • Oracle’s code is never edited. Changes go in the CUSTOM layer and Oracle values are checked, so upgrades stay safe.
  • Nothing without approval. You see the plan and the files before anything is built.
  • No secrets in files. Passwords and keys are left as placeholders for your team.
  • Your data stays yours. Uploaded objects are used for your job only, and a private install keeps everything inside your network.

Real jobs, real results

On a live FLEXCUBE 14.7 environment, TrustForge built a new customer risk profile screen (STDCURSK) that is now deployed and in use. On another job it added a complete sixth charge to Oracle’s ARC maintenance (IFDATMMN): 36 new fields in the CUSTOM layer, with no Oracle values changed.

Start free

The Free plan includes radxml reviews and ODT questions. The Partner plan is $100 USD per seat per month with all six job types, and banks can arrange a private install in their own cloud. For many changes, that means up to 90% lower development cost; savings depend on scope, and your team still reviews, deploys and tests every change.

Start your first job at forge.trustroutetechnologies.com, or read more on the TrustForge page.
